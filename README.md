# Capstone_project_ict
Developed a deep learning-based framework to enhance the resolution of low-resolution satellite images using ESRGAN. The proposed approach aims to combine image super-resolution with uncertainty quantification through techniques such as Monte Carlo Dropout or Bayesian methods, generating uncertainty heatmaps to indicate the reliability of reconstructed details. The project focuses on applications such as disaster management, agricultural monitoring, and urban planning, using satellite imagery datasets like SpaceNet and Sentinel-2.
